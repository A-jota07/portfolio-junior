# 🟣 Developer Portfolio | Minimalist Terminal & React UI

![Portfolio Preview](https://raw.githubusercontent.com/seu-usuario/seu-repositorio/main/public/preview.png)

> **Portfólio Pessoal & Showcase de Projetos**  
> Uma aplicação web SPA minimalista desenvolvida em React, inspirada em editores de código e interfaces estilo terminal, com um tema escuro em tons de roxo/magenta.

---

## 🚀 Sobre o Projeto

Este projeto foi construído para centralizar e apresentar minha trajetória acadêmica e profissional, projetos de desenvolvimento de software e habilidades técnicas. A interface combina estética *cyberpunk/terminal* com componentes modernos em React e Tailwind CSS.

### ✨ Funcionalidades Principais
* **Hero Section Interativa:** Apresentação em estilo bloco de código com minhas informações e contatos.
* **Showcase Dashboard:** Widget interativo simulando métricas de repositórios/projetos.
* **Seção de Projetos & Skills:** Exibição clara das stacks de cada projeto com filtros visuais.
* **Design Responsivo & Temático:** Layout otimizado com palette `Midnight Navy` & `Electric Purple`.

---

## 🛠️ Tech Stack

* **Front-end:** [React](https://react.dev/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Ícones:** [Lucide React](https://lucide.dev/)
* **Deploy:** [Vercel](https://vercel.com/) / [Netlify](https://netlify.com/)
